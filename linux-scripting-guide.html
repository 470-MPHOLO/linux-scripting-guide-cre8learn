What Is a Shell Script?

A shell script is a text file containing a series of Linux commands that run automatically. Instead of typing commands one by one, you write them once and execute them as a single program.

Scripts are used for:

  • Automating repetitive tasks
  • Managing files and directories
  • Monitoring system health
  • Running backups
  • Deploying applications

On RHEL, the default shell is Bash (Bourne Again Shell).

Your First Script

Create a file called hello.sh:

#!/bin/bash
# My first script
echo "Hello, Cre8Learn!"

Line 1: #!/bin/bash is called the shebang. It tells Linux to use Bash to run the script. Always include it.

Line 2: A comment. Comments start with # and are ignored.

Line 3: echo prints text to the screen.

Make it executable and run it:

chmod +x hello.sh
./hello.sh

Variables

Variables store data.

#!/bin/bash
name="Teboho"
course="Linux"
echo "Welcome $name to $course"

Rules:

  • No spaces around =
  • Use $variable to read the value
  • Use "$variable" in quotes when it might contain spaces

User input:

read -p "Enter your name: " username
echo "Hello, $username"

Command output into a variable:

today=$(date +%F)
echo "Today is $today"

Conditionals

Use if to make decisions.

#!/bin/bash
read -p "Enter a number: " num

if [ "$num" -gt 10 ]; then
    echo "Greater than 10"
elif [ "$num" -eq 10 ]; then
    echo "Exactly 10"
else
    echo "Less than 10"
fi

Common test operators:

OperatorMeaning
-eqequal
-nenot equal
-gtgreater than
-ltless than
-ffile exists
-ddirectory exists
-zstring is empty

Loops

For loop (iterate over a list):

#!/bin/bash
for user in alice bob charlie; do
    echo "Processing $user"
done

For loop over files:

for file in /var/log/*.log; do
    echo "Log file: $file"
done

While loop (repeat while a condition is true):

#!/bin/bash
count=1
while [ $count -le 5 ]; do
    echo "Count: $count"
    ((count++))
done

Functions

Functions group commands for reuse.

#!/bin/bash

greet() {
    echo "Hello, $1"
}

greet "Cre8Learn"
greet "RHEL Students"

$1 is the first argument passed to the function.

Practical Example: System Health Check

#!/bin/bash
# check_system.sh - basic RHEL health check

echo "===== System Report ====="
echo "Hostname: $(hostname)"
echo "Uptime: $(uptime -p)"
echo "Disk Usage:"
df -h / | tail -1
echo "Memory Usage:"
free -h | grep Mem
echo "Logged-in Users:"
who
echo "========================="

Save as check_system.sh, then:

chmod +x check_system.sh
./check_system.sh

Debugging Tips

  • Run with bash -x script.sh to see each command as it executes.
  • Use echo statements to print variable values.
  • Always test scripts in a safe directory first.
  • Check exit codes with echo $? after a command runs.

Best Practices

  1. Always start with #!/bin/bash.
  2. Comment your code. Future you will thank present you.
  3. Quote your variables: "$var" not $var.
  4. Use meaningful names: backup_dir not bd.
  5. Test before automating anything critical.
  6. Keep scripts in one folder, e.g., ~/scripts.
  7. Use set -e at the top to make the script exit on any error.
